# Simple 1v1 Turn-Based Combat

A small C++ console game made as a learning project.

The player chooses a weapon and fights a randomly generated monster in a simple turn-based battle. Each weapon has a random damage range, and the fight continues until either the player or the monster reaches 0 HP.

## Features

- Player name input
- Weapon selection
- Random monster generation
- Different weapons for players and monsters
- Random damage values
- Turn-based combat
- HP and death checking
- Basic input validation

## Concepts Practiced

- Classes and objects
- Constructors
- Enums
- Member functions
- References
- Header and source file separation
- Loops and conditionals
- Random number generation
- Basic game logic

## Current Limitations

- Game balance is still being adjusted
- Combat is currently only 1v1
- No special abilities, critical hits, or advanced combat mechanics

## Future Ideas

- Difficulty selection
- Multiple monsters
- 1v3 sequential battles
- 1v3 battles with multiple enemies attacking
- Party-based combat
